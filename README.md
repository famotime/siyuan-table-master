# 表哥 (Table Master)

**专治 Markdown 表格的各种不服**

思源笔记表格增强插件 —— 把思源原生表格进化成趁手的「轻量电子表格」，让你像用 Excel 一样流畅地编辑 Markdown 表格。

---

## 为什么需要表哥？

在思源笔记中，表格是高频使用的内容载体。然而原生 Markdown 表格在实际使用中有不少让人抓狂的地方：

| 你想做的事 | 原生体验 | 表哥帮你 |
| :--- | :--- | :--- |
| 从 Excel / 网页复制一段表格数据 | 粘贴后格式碎裂，变成一堆零散文本 | ✅ **智能粘贴**：自动识别并转换为标准表格 |
| 把一段逗号 / Tab 分隔的文本变成表格 | 手动加 `\|` 和 `---`，效率极低 | ✅ **文本转表格**：选中文本一键转换 |
| 编辑长表格时向下滚动 | 表头消失，不知道每列是什么 | ✅ **钉住表头**：表头自动固定在视口顶部 |
| 调换两行 / 两列的顺序 | 只能靠快捷键，不够直观 | ✅ **拖拽重排**：拖拽手柄直接拖动 |
| 临时看一下几个数字的合计 | 得掏计算器或手写公式 | ✅ **即时计算**：Alt + 拖选即显求和 / 均值 / 计数 |
| 快速调整表格大小 | 逐行逐列手动添加 | ✅ **可视化调整**：网格拖选批量增行增列 |

## 功能一览

### 📋 数据送入 —— 告别格式碎裂

#### 智能粘贴（Smart Paste）

从 Excel、飞书文档、Notion、网页等外部来源复制的表格数据，粘贴到思源时**自动识别并转换**为标准 Markdown 表格，告别格式碎裂的尴尬。

- 支持 HTML 表格（`<table>`）、TSV（制表符分隔）等多种格式
- 当粘贴内容会覆盖已有数据时，弹出确认对话框，防止误操作
- 可在设置中开关，默认开启

#### 文本转表格（Text to Table）

选中一段以逗号、Tab、空格等符号分隔的文本，一键转换为标准表格：

1. 选中多行文本
2. 通过命令面板（`Ctrl+P`）搜索「文本转为表格」，或在右键菜单 / 侧栏面板中点击
3. 在弹出的设置窗口中选择分隔符和表头选项
4. 确认后自动生成表格并替换原文本

### ✏️ 日常编辑 —— 行云流水

#### 单元格导航

| 操作 | 快捷键 |
| :--- | :--- |
| 跳到下一单元格 | `Tab` |
| 跳到上一单元格 | `Shift + Tab` |
| 跳到下一行 | `Enter` |

#### 行列操作

所有操作均可通过**浮动工具栏**、**侧栏面板**或**命令面板**触发：

| 操作 | 说明 |
| :--- | :--- |
| 插入行 / 列 | 在光标位置的下方 / 右侧插入 |
| 删除行 / 列 | 删除光标所在的行 / 列 |
| 上移行 / 下移行 | 整行上下移动（快捷键 `Ctrl+Alt+T` / `Ctrl+Alt+B`） |
| 左移列 / 右移列 | 整列左右移动（快捷键 `Ctrl+Alt+L` / `Ctrl+Alt+R`） |
| 复制行 / 列 | 将整行或整列复制到剪贴板 |
| 粘贴行 / 列 | 将已复制的行 / 列粘贴到光标位置，带覆盖确认 |

#### 调整表格大小（Resize Table）

光标置于表头时，浮动工具栏出现**调整表格**按钮，点击展开可视化网格面板，鼠标悬停选择目标尺寸，单击即可批量增加行列。

#### 对齐与格式化

| 操作 | 快捷键 |
| :--- | :--- |
| 列左对齐 | `Alt + L` |
| 列居中对齐 | `Alt + C` |
| 列右对齐 | `Alt + R` |
| 格式化表格 | 自动统一列宽、对齐管道符 |

#### 排序与转置

- **升序 / 降序排序** —— 按当前列的内容排序所有数据行
- **转置** —— 行列互换（表头变第一列，第一列变表头）

---

### 🔢 数据计算 —— 无需写公式

#### 即时计算（Quick Calc）

按住 `Alt` 键 + 鼠标拖选多个单元格，实时显示选区的：
- **求和**（Sum）
- **平均值**（Average）
- **计数**（Count）

类似 Excel 右下角的状态栏，免去为了临时算个数还要去写公式的麻烦。

#### 行求和 / 列求和

- 光标在**最右侧列**时，浮动工具栏出现「行求和」按钮 —— 自动在末列追加该行数值的合计
- 光标在**最下方行**时，浮动工具栏出现「列求和」按钮 —— 自动在末行追加该列数值的合计

---

### 📊 数据可视化 —— 一键图表化

光标在表头时，浮动工具栏出现「图表化」按钮，点击后自动基于表格数据在下方生成 ECharts 图表块（柱状图、折线图等），省去手写 ECharts 配置的烦恼。

---

### 👁️ 阅读体验 —— 长表不迷路

#### 钉住表头（Sticky Header）

光标在表头时，浮动工具栏出现「钉住表头」切换按钮。开启后，无论表格多长，向下滚动时表头始终固定在编辑器顶部，方便长数据的比对和补录。

#### 拖拽行列重排（Drag & Drop）

光标在表格内时，当前行左侧和当前列上方出现微小的**拖拽手柄**。按住手柄拖动，蓝色指示线标记目标位置，松开即完成重排。比快捷键更直观的行列调整方式。

## 操作入口

表哥提供 **4 种操作方式**，适配不同操作习惯：

| 入口 | 说明 |
| :--- | :--- |
| 🎯 **浮动工具栏** | 光标在表格内时自动出现在单元格附近，提供当前上下文最相关的操作按钮 |
| 🧰 **侧栏工具箱** | 右侧 Dock 面板，集中展示所有操作按钮 + 快捷键指南，附带表格状态显示 |
| ⌨️ **快捷键** | `Tab` / `Enter` 导航、`Alt+L/C/R` 对齐、`Ctrl+Alt` 组合移动行列等 |
| 🔍 **命令面板** | `Ctrl+P` 搜索任意命令名称（中文 / 英文均可） |

### 浮动工具栏详情

浮动工具栏会根据**光标所在位置**智能展示不同按钮：

- **光标在表头**：调整表格大小、对齐方式（左/中/右）、升序/降序排序、转置、钉住表头、图表化
- **光标在数据行**：上移行、下移行、左移列、右移列、复制行/列；当有已复制内容时额外显示粘贴按钮；光标在边缘行列时显示求和按钮

## 安装

### 从集市安装（推荐）

在思源笔记「设置 → 集市 → 插件」中搜索 **表哥** 或 **Table Master** 即可安装。

### 手动安装

1. 从 [Releases](https://github.com/famotime/siyuan-advanced-tables/releases) 下载最新 `package.zip`
2. 解压到 `{工作空间}/data/plugins/siyuan-table-mater/`
3. 在「设置 → 插件」中启用

---

## 设置项

| 选项 | 默认 | 说明 |
| :--- | :--- | :--- |
| 浮动工具栏 | ✅ 开启 | 光标在表格内时显示浮动操作栏 |
| 智能粘贴 | ✅ 开启 | 自动识别 Excel / 网页 / TSV 表格数据并转换 |
| 即时计算 | ✅ 开启 | Alt + 鼠标拖选时实时显示统计信息 |
| 拖拽重排 | ✅ 开启 | 显示行列拖拽手柄，拖动即可调整顺序 |
| CJK 宽度校正 | ✅ 开启 | 修正中文等全角字符的列宽计算，格式化更整齐 |
| 顶栏图标 | ✅ 开启 | 在顶部工具栏显示插件图标 |
