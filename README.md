# 表哥 (Table Master)

**专治思源 Markdown 表格的各种不爽！**

思源笔记表格增强插件 —— 把思源原生的 Markdown 表格进化为趁手的「轻量电子表格」，让你像用 Excel 一样流畅、智能、安全地编辑和计算数据。

---

## 💡 为什么需要表哥？

在思源笔记中，表格是承载结构化信息的高频工具。然而，原生 Markdown 表格在实际使用中存在许多令人抓狂的痛点。表哥插件正是为此而生：

| 你的日常使用场景 | 原生思源体验 | 💻 使用表哥的体验与价值 |
| :--- | :--- | :--- |
| **数据迁移**：从 Excel / 网页 / 终端复制一段表格数据 | 粘贴后格式碎裂，变成一堆零散文本 | ✅ **智能粘贴**：自动识别多格式剪贴板，一键秒变标准表格，免去手动重构。 |
| **数据求和**：想临时算一下几行数据的总和与均值 | 必须手写公式或掏出计算器挨个累加 | ✅ **直接拖选计算**：鼠标直接框选，底部与侧栏秒显求和、均值与计数，甚至显示行列范围。 |
| **顺序调整**：调换行/列的顺序，或复制转移 | 只能靠繁琐的剪贴配合，极易弄乱已有数据 | ✅ **拖拽重排与插入粘贴**：拖拽手柄直观调整；**安全“插入式粘贴”**，不覆盖已有数据。 |
| **排版优化**：宽表格或长文本表格宽度难看 | 需要繁琐的手动拉伸或容忍难看的折行 | ✅ **一键列宽自适应**：点一下“调宽度”，表格根据内容自动紧凑排列，排版清爽。 |
| **长表浏览**：向下滚动阅读或编辑超长表格 | 表头滚出视口，完全分不清每列数据对应什么 | ✅ **钉住表头**：表头自动悬浮固定在视口顶部，长数据比对和补录清晰直观。 |

## 🚀 主要功能特性

### 📋 智能导入，一键成表
*   **智能粘贴 (Smart Paste)**：支持 HTML 表格（`<table>`）、TSV（制表符分隔文本）等多源数据。直接复制粘贴，格式不碎裂。
*   **文本转表格 (Text to Table)**：选中多行以逗号、Tab、空格分隔的纯文本，通过侧栏或命令面板一键转换为标准表格。
*   **一键表格宽度自适应**：一键让表格在“紧凑自适应排版”与“拉满宽度”之间自由切换，拯救强迫症，完美适配不同字数的表格内容。

### ✏️ 畅快编辑，随心所欲
*   **拖拽行列重排**：光标移动到表格中时，当前行左侧和列上方会出现小巧的拖拽手柄。拖动它们，顺着蓝色指示线即可直观重排。
*   **剪切行 / 剪切列**：如果行列需要移动的位置较远，可以使用本功能完成移动，比拖拽更方便。
*   **对齐与格式化**：一键设置整列左对齐/居中对齐/右对齐。支持美化格式，自动统一 Markdown 列宽和管道符。
*   **排序与转置**：支持按当前列字符/数值升序或降序重排所有数据行；或一键进行行列转置（行变列，列变行）。

### 🔢 智能计算与可视化
*   **极速行/列求和**：光标移动到边缘时，点击浮动工具栏的求和按钮，即可自动在最末行/最末列追加该行或该列数值的合计，免写公式。
*   **一键数据图表化**：光标聚焦表头时，点击工具栏的“图表化”按钮，插件会自动根据当前表格数据，在下方生成配套的 ECharts 可视化图表块（柱状图、折线图等）。

## 🎯 4 种操作入口

表哥提供了多维度交互设计，适配不同操作习惯：

1.  🎯 **浮动工具栏**：光标在表格内时自动出现在单元格附近，只展示当前光标位置最相关的快捷操作（例如在表头显示排序和转置，在边缘行列显示求和）。
2.  🧰 **侧栏工具箱（表哥工具箱）**：在思源右侧 Dock 栏常驻。集中提供完整的分类功能按钮，展示实时表格状态，并附带可一键开启/关闭悬浮工具栏的快捷开关。
3.  ⌨️ **键盘快捷键**：配合 `Ctrl + Alt` 移动行列、`Alt + L/C/R` 对齐、以及 `Alt + 拖选` 的传统计算模式，全键盘流派的福音。

## ⌨️ 快捷键速查

| 快捷键 | 对应操作 | 场景与价值 |
| :--- | :--- | :--- |
| `鼠标直接拖选` | 即时计算（求和/均值/计数） | 临时统计数据的神器，浮动工具栏会自动隐藏 |
| `Alt + 鼠标拖选` | 即时计算（保留传统模式） | 兼容习惯，强制启用框选计算 |
| `Alt + L` | 当前列左对齐 | 快速规范文本列排版 |
| `Alt + C` | 当前列居中对齐 | 快速规范序号、状态列排版 |
| `Alt + R` | 当前列右对齐 | 快速规范数值、金额列排版 |
| `Ctrl + Alt + T` | 向上移动整行 | 免拖拽快速调换行顺序 |
| `Ctrl + Alt + B` | 向下移动整行 | 免拖拽快速调换行顺序 |
| `Ctrl + Alt + L` | 向左移动整列 | 免拖拽快速调换列顺序 |
| `Ctrl + Alt + R` | 向右移动整列 | 免拖拽快速调换列顺序 |
| `Ctrl + -` | 删除当前整行 | 快速裁剪多余行 |
| `Ctrl + Shift + -` | 删除当前整列 | 快速裁剪多余列 |
| `Escape` | 清除多选计算状态 | 退出框选状态并收起计算面板 |

*注：`Tab` / `Shift + Tab` / `Enter` 完美继承思源原生表格导航逻辑，不再额外拦截。*

## 📦 安装与升级

### 方法一：从集市安装（推荐）
在思源笔记内打开「设置 → 集市 → 插件」，搜索 **表哥** 或 **Table Master**，点击安装即可。

### 方法二：手动安装
1.  从 [GitHub Releases](https://github.com/famotime/siyuan-table-master/releases) 下载最新的 `package.zip`。
2.  解压后将文件夹放入思源工作空间目录：`{工作空间}/data/plugins/siyuan-table-master/`。
3.  在「设置 → 插件」中找到“表哥”并启用。
