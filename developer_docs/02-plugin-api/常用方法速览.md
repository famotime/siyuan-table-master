# 常用方法速览

- 适用版本：SiYuan `v3.7.3` / npm `siyuan@1.2.3`
- 最后核对：2026-08-02
- 稳定性：stable
- 权威来源：
  - <https://github.com/siyuan-note/petal/blob/main/siyuan.d.ts>
  - <https://github.com/siyuan-note/siyuan/blob/master/app/src/plugin/index.ts>

## 1. 网络与消息

### `fetchPost` / `fetchSyncPost`

```ts
fetchPost(
  url: string,
  data?: unknown,
  cb?: (response: IWebSocketData) => void,
  headers?: IObject,
): void;

fetchSyncPost(url: string, data?: unknown): Promise<IWebSocketData>;
```

建议优先封装 Promise 风格的 `fetchSyncPost`，集中处理 `code`、`msg`、日志和降级。高频请求应节流、合并或取消，避免阻塞 UI。

### `showMessage` / `hideMessage` / `confirm`

```ts
showMessage(text: string, timeout?: number, type?: "info" | "error", id?: string): void;
hideMessage(id?: string): void;
confirm(title: string, text: string, confirmCallback?: (dialog: Dialog) => void): void;
```

`showMessage` 返回/接收的消息 ID 可用于提前隐藏长时操作提示；删除、覆盖、批量写入等高风险操作应先 `confirm`。

## 2. 页面、编辑器与环境

### `openTab` / 活动页签

```ts
openTab(options: {
  app: App;
  doc?: { id: string; action?: string; zoomIn?: boolean };
  custom?: { id: string; icon: string; title: string; data?: unknown };
  position?: "right" | "bottom";
  openNewTab?: boolean;
}): ITab;

getAllTabs(type?: string): Array<...>;
getActiveTab(): ITab | undefined;
getActiveEditor(): Protyle | undefined;
```

`getAllTabs` 在新版本中支持可选 `type` 参数。需要兼容旧版本时，可先尝试带参调用，再回退到无参数过滤。

### `getFrontend` / `getBackend`

```ts
getFrontend(): "desktop" | "desktop-window" | "mobile" | "browser-desktop" | "browser-mobile";
getBackend(): "windows" | "linux" | "darwin" | "docker" | "android" | "ios";
```

按前端和后端组合决定功能降级，不要只用 User-Agent 判断平台。

### `Protyle.switchMode`

`Protyle` 在 v3.7.x 增加 `switchMode`，用于切换编辑模式。调用前应确认编辑器仍存活；跨版本插件可对方法存在性做保护。

## 3. 导出与事务

### `saveExportFile`

用于把插件生成的文件保存到导出流程。导出内容可能包含用户数据，文件名、扩展名和路径必须校验，避免覆盖非目标文件。

### `updateTransactionElement`

v3.7.0 起 `updateTransaction` 已弃用，应改用 `updateTransactionElement`。弃用 API 被调用时会输出警告日志，建议在发布前清空相关警告。

## 4. 密钥与变量

```ts
const secret = this.getSecret("SERVICE_TOKEN");
const variable = this.getVariable("SERVICE_ENDPOINT");

if (!secret) {
  throw new Error("未配置 SERVICE_TOKEN");
}
```

- 名称不存在时返回空字符串，必须判空。
- 密钥磁盘侧加密，但前端插件读取到的是运行时明文。
- 不要把密钥放进日志、DOM、通知、异常文本、遥测或 AI 返回值。
- 变量适合非敏感配置；敏感凭据必须使用密钥。
- 设置密钥和变量的内核接口受鉴权、管理员角色和只读状态约束；读取方法从已加载配置取值。

## 5. AI 智能体动作

```ts
this.addAgentAction({
  name: "lookup_block",
  description: "按块 ID 查询摘要；参数 id 为非空字符串",
  handler: async (args, app) => {
    if (typeof args.id !== "string" || !args.id) {
      return { error: "参数 id 无效" };
    }

    // 使用 app 或内核 API 执行查询。
    return { result: `block: ${args.id}` };
  },
});
```

签名：

```ts
addAgentAction(options: {
  name: string;
  description: string;
  handler: (
    args: Record<string, unknown>,
    app: App,
  ) => Promise<{ result?: string; error?: string }>;
}): string;
```

- 完整动作名为 `plugin__<pluginName>__<actionName>`。
- `name` 使用稳定的小写标识符；`description` 明确参数和副作用。
- handler 必须自行校验参数，仅返回 `{ result }` 或 `{ error }`。
- 涉及删除、写文件、外发数据的动作必须二次确认。
- 插件卸载时已注册动作会自动注销。

## 6. 内核插件入口

`Plugin.kernel` 提供内核插件状态和 RPC。只有插件包实际包含 `kernel.js` 并在 `plugin.json` 声明 `kernels` 时才使用：

```ts
if (this.kernel.state.code === 2) {
  const result = await this.kernel.rpc.call.example({ value: 1 });
}
```

状态码 `2` 表示 `running`；启动前调用可能返回 `-32002`。通过 `kernel-plugin-state-change` 事件等待就绪，并对错误提供降级。

## 7. 统一请求封装

```ts
import { fetchSyncPost, showMessage } from "siyuan";

export async function requestApi<T>(url: string, data?: unknown): Promise<T> {
  const response = await fetchSyncPost(url, data);
  if (response.code !== 0) {
    showMessage(`API error: ${response.msg || url}`, 5000, "error");
    throw new Error(response.msg || `Request failed: ${url}`);
  }
  return response.data as T;
}
```

调用内部 API 时，应在此封装之外再增加版本探测和 fallback，避免把内部路由伪装成稳定接口。
