# 思源笔记高级表格插件 - 开发计划

- 文档版本：v1.0
- 创建日期：2026-06-20
- 配套文档：[`01-设计方案.md`](./01-设计方案.md)
- 计划周期：约 8 周（5 个里程碑，M0~M4）
- 开发模型：里程碑驱动 + 每里程碑内 TDD（参考 test-driven-development 技能）

---

## 0. 总览

| 里程碑 | 名称 | 时长 | 目标 | 交付物 |
|---|---|---|---|---|
| **M0** | 决策与原型验证 | 1 周 | 消除设计方案 9 节 4 个待决项；跑通最小适配 | 原型 demo + 决策记录 |

每里程碑结束有**明确验收标准**（DoD），不达标不进入下一阶段。

## M0：决策与原型验证（第 1 周）

> 目的：在设计方案基础上，把 4 个"待评审决策点"用可运行代码验证，避免在 M1 才发现架构假设错误。

### 任务

| # | 任务 | 类型 | 验收标准 |
|---|---|---|---|
| 0.1 | 安装核心库 `npm i @tgrosinger/md-advanced-tables`，确认能 import | 工程 | 构建通过 |
| 0.2 | **原型：写回路径二选一** | 决策 | 对比 `updateTransactionElement` vs `/api/block/updateBlock`，记录选型理由 |
| 0.3 | **原型：kramdown 往返测试** | 决策 | 对 5 个真实表格（含对齐/空单元格/转义/IAL），验证 kramdown → 核心库解析 → flush → DOM 无失真 |
| 0.4 | **原型：光标行列映射** | 决策 | 在 3×3 表格中，每个单元格点击都能反推正确的 (row, col) |
| 0.5 | **原型：Tab 拦截** | 决策 | 捕获阶段拦截 Tab，仅表格内 nextCell 生效，表格外不受影响；中文输入法下不吞确认键 |
| 0.6 | **原型：公式承载** | 决策 | 验证公式行作为表格块内部尾部 markdown 的可行性，或确定改用块属性存储 |
| 0.7 | 写 `docs/02-技术决策记录.md` 沉淀结论 | 文档 | 4 个决策点全部定稿 |

### 退出标准（DoD）

- [ ] 核心库依赖就位且可构建。
- [ ] 一段手写的 `SiyuanTextEditor.transact` 原型能对真实思源表格完成"格式化"且 undo 可用。
- [ ] 技术决策记录文档完成，4 个待决项全部 close。

## M1：适配层与 MVP（第 2–3 周）

> 目的：把原型扩展为完整的 `SiyuanTextEditor`，覆盖设计方案 4.1 的 MVP 功能。

### 第 2 周：适配层与命令骨架

| # | 任务 | 说明 |
|---|---|---|
| 1.1 | 完善 `SiyuanTextEditor` | 全部 ITextEditor 方法，含内存行模型 + reload/flush + 操作锁（串行化） |
| 1.2 | `dom-utils.ts` | `findTableBlockFromRange()` / `rangeToCellCoord()` / `cellCoordToRange()` |
| 1.3 | `lute-bridge.ts` | 封装 markdown↔DOM，剥离/保留块 IAL |
| 1.4 | `table-editor.ts` | 对标参考项目，转发 20+ 方法 |
| 1.5 | `commands.ts` + `index.ts` 命令注册 | 注册 MVP 命令到 `addCommand` |
| 1.6 | `keybind.ts` | Tab/Shift+Tab/Enter 拦截，绑定到编辑器生命周期事件 |

**TDD 重点**（适配层是风险最高的代码）：
- `SiyuanTextEditor` 的行模型：用纯函数拆分 `parseLines`/`serializeLines`，单元测试覆盖对齐行、空表、转义。
- `rangeToCellCoord` 的反推：对固定 DOM 结构做快照测试。

### 第 3 周：MVP 功能联调

| # | 任务 |

| 1.7 | 格式化（format-table）端到端 |
| 1.8 | Tab/Shift+Tab 导航端到端 |
| 1.9 | Enter 下一行（含 isComposing 兼容） |
| 1.10 | 插入/删除行列、移动行列 |
| 1.11 | 列对齐（左/中/右） |

## 附录 A：手动测试用例清单（M1 起逐步覆盖）

> 每个用例：操作 → 预期。括号标注覆盖里程碑。

### A.1 基础导航（M1）
1. 3×3 表格，单元格 A 点 Tab → 光标到 B，再 Tab 到 C，再 Tab → 新建一行回到首列。
2. Shift+Tab 反向遍历。
3. 表格内 Enter → 跳到下一行同列；最后一行 Enter → 新增行。
4. 表格外 Tab → 不拦截，正常缩进/焦点切换。

### A.2 编辑（M1）
5. 插入列 → 当前列左侧出现空列，光标移入。
6. 删除列 → 当前列消失，光标到相邻列。
7. 移动列左/右 → 列顺序变化，数据不丢。
8. 左/中/右对齐 → 分隔行 `:---` `:--:` `---:` 正确更新。

### A.3 格式化（M1）
9. 手动缩进的乱表格 → 格式化后列宽对齐（中英文混合）。
10. undo → 回到乱表格状态。

### A.4 高级（M2）
11. 数字列升序/降序排序，表头不动。
12. 转置 3×4 → 4×3。
13. 公式行 `<!-- ... -->` 或约定格式 → 求值后填充结果单元格。
14. CSV 导出 → 文本框内容可复制，含/不含表头切换。

### A.5 边界（M3）
15. 单行表格、单列表格所有命令不报错。
16. 100×100 表格格式化 < 500ms。
17. 只读文档下命令被禁用或友好提示。
18. 中文输入法打字中途不触发 Tab 拦截。
