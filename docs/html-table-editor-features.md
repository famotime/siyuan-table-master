# HTML 表格高级编辑器功能介绍与工具栏按钮特性详解

> **适用版本**：siyuan-table-master v1.1.6+  
> **文档分类**：功能特性手册 / 工具栏参考指南  
> **面向对象**：插件使用者、笔记排版创作者、数据报表制作者

---

## 1. 背景与概述

在思源笔记中，原生 Markdown 表格（`NodeTable`）具有轻量、结构简洁的优势，但在需要制作**跨行跨列复杂报表、丰富视觉配色、精细行列尺寸调整、冻结行列以及单元格公式计算**等场景下，原生 Markdown 表格的能力受到格式标准的限制。

为了解决这一痛点，本插件提供了 **HTML 复杂表格高级编辑器**（基于 `NodeHTMLBlock` HTML 块）。编辑器采用“所见即所得 (WYSIWYG)”的现代工作台架构，集成了 **Word 级排版美化 + Excel 级公式计算与填充 + 原生级拖拽交互**，同时保证输出代码符合标准 HTML 规范，在移动端、PDF 导出、网页分享时均能 100% 完美保真。

---

│ └──────────────────────┘  └───────────────────────────────────┘  └───────────────────┘ │
├──────────────────────────────────────────────────────┬─────────────────────────────────┤
│                                                      │ 3. 侧边工具面板 (Side Panel)    │
│ 2. 主编辑画布与拖拽交互区 (Canvas)                   │   [收缩/展开切换按钮 ‹/›]       │

│ • 悬浮边缘显现蓝色调整手柄（列宽/行高）               │ │ ① 行列与结构 (增删移复/升降序)│ │
│ • 拖拽全局对齐参考线 + 实时尺寸气泡 (px / pt)        │ │ ② 排版对齐 (水平/垂直各3种)  │ │

├──────────────────────────────────────────────────────┴─────────────────────────────────┤

└────────────────────────────────────────────────────────────────────────────────────────┘

此外，还配备了 **右键快捷上下文菜单 (Context Menu)**、**浮动工具栏胶囊 (Floating Toolbar)** 以及 **拖拽式公式向导弹窗**。

## 5. 画布直观拖拽与交互特性

### 5.1 边缘手柄与尺寸指示（Drag & Resize）
- **列宽手柄 (`at-col-resize-handle`)**：鼠标移动到任意单元格右侧边缘时，出现蓝色交互拖拽条。按住向左/向右拖拽，整列宽度实时随动。
- **行高手柄 (`at-row-resize-handle`)**：鼠标移动到单元格下边缘时，出现蓝色拖拽条。按住向下拖拽即可拉伸整行高度。
- **全屏对齐参考线 (Guide Line)**：拖拽时画布自动延伸出纵向（蓝色竖线）或横向（蓝色横线）参考基准线，辅助视觉对齐。
- **尺寸跟随气泡 (Resize Bubble)**：拖拽时光标右上角实时浮现动态气泡，同时展示像素（px）与磅值（pt），如 `列宽 140px · 105pt`。

### 5.2 矩形区域平滑多格框选
- 按住鼠标左键滑动，即可生成连续的半透明蓝色多选矩形选区。
- **底部状态栏实时汇总**：框选包含数字的单元格时，底部状态栏会**即时自动计算并输出所选格数、数值总和 (Sum) 与算术平均值 (Average)**（例如：`选中 8 格 · 求和: 12,580 · 均值: 1,572.5`）。

### 5.3 双击行内直接编辑
- 鼠标双击任意单元格，即可激活行内直接编辑模式（`contentEditable`）；
- 若单元格包含公式（如 `=SUM(A1:A5)`），双击时自动呈现公式源码文本供编辑；
- 快捷键支持：按 `Enter` 完成保存并退出编辑，按 `Shift + Enter` 插入软换行，按 `Esc` 放弃修改退出。

## 6. 公式计算引擎与向导

### 6.1 可拖拽公式向导弹窗
点击顶部工具栏【公式】或右键选择【插入计算公式】后唤起公式向导：
1. **窗口防遮挡拖拽**：鼠标按住弹窗顶部的拖拽手柄条，可将弹窗自由拖动至屏幕任意位置，避免遮挡底层表格数据；
2. **动态表格坐标系**：开启弹窗时，画布四周自动标注 **列字母（A, B, C...）** 与 **行号（1, 2, 3...）**，并高亮当前选区坐标；
3. **语法帮助浮窗**：点击右上角【?】图标可随时展开完整语法指南与区域引用说明；
4. **快捷函数 Chips**：点击弹窗内的 `SUM`、`AVERAGE`、`COUNT` 等快捷按钮，自动将选区坐标包装为公式填入输入框；
5. **实时计算预览**：在输入框中打字时，弹窗下方即时显示计算结果或语法错误警告。

### 6.2 支持的聚合函数与运算

所有公式均必须以 `=` 开头：

| 函数 / 语法 | 示例用法 | 计算特性说明 |
| :--- | :--- | :--- |
| **SUM** | `=SUM(A1:A5)` 或 `=SUM(A1:D1)` | 对指定连续横向/纵向区域内所有数值求和 |
| **AVERAGE** | `=AVERAGE(B2:B10)` | 计算区域内有效数字的算术平均值 |
| **COUNT** | `=COUNT(C:C)` 或 `=COUNT(A1:D5)` | 统计区域内包含数值的有效单元格总数 |
| **MAX** | `=MAX(A1:E5)` | 获取指定区域内的最大数值 |
| **MIN** | `=MIN(A1:E5)` | 获取指定区域内的最小数值 |
| **MEDIAN** | `=MEDIAN(B1:B9)` | 计算指定区域数值的中位数 |
| **PRODUCT** | `=PRODUCT(A1:A4)` | 将区域内所有数值连乘求积 |
| **四则与括号运算** | `=A1+B1*1.2` 或 `=(A1+B1)/2` | 支持标准加减乘除与括号运算符优先级 |
| **绝对锁定引用** | `=$A$1+B1` | 使用 `$` 锁定行列坐标，智能填充时不随位移发生变化 |

## 9. 注意事项与最佳实践

1. **表格转置限制**：包含跨行或跨列合并单元格（`rowSpan > 1` 或 `colSpan > 1`）的表格无法执行转置，需先拆分合并单元格后方可转置。
2. **公式计算特性**：公式计算由前端实时执行，保存为 HTML 时会自动将求值结果写回标准标签文本中，确保即使在未安装本插件的设备或导出 PDF 时依然能够正确呈现计算数值。
3. **与原生 Markdown 表格互转**：
   - 可在思源笔记中通过斜杠命令或快捷命令执行 `html-to-md` 将 HTML 表格转换为原生 Markdown 表格；
   - 在弹窗编辑器中，点击顶部【导入】按钮即可直接输入 Markdown 表格代码一键升格为 HTML 复杂表格。
4. **移动端与外链保真**：本编辑器生成的所有 HTML 表格采用纯内联 CSS 属性与标准 `<table>` 语义结构，不依赖任何外部 CSS 类名或运行时 JS 库，在思源笔记移动端 App、发布至思源网页端、导出 PDF 及打印排版时均能保持 100% 像素级一致。
