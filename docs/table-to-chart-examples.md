# 一键数据图表化（Table to Chart）业务场景示例数据

本文件提供了多个实际业务场景的数据表格示例。您可以直接将这些表格复制到思源笔记中，并使用高级表格插件的“一键数据图表化”功能，在表格下方生成对应的 ECharts 原生图表块。

本示例涵盖了常用的三种图表类型（柱状图、折线图、饼图），并包含了千分位、百分比和货币符号等复杂数值格式，以验证数据清洗器的表现。

---

## 场景一：月度营收与净利润分析 (适合：柱状图 / 折线图)

该场景包含多列数值数据，展示了销售量、营业额与利润率。用于测试：
- X 轴：`月份` (类目轴)
- Y 轴：`销量` (纯整数数值)、`营业额` (带货币符号和千分位)、`净利润率` (带百分号的小数)

| 月份 | 销量 (件) | 营业额 (元) | 净利润率 |
| :--- | :--- | :--- | :--- |
| 一月 | 120 | $15,600.00 | 12.5% |
| 二月 | 145 | $18,900.50 | 14.2% |
| 三月 | 190 | $24,500.00 | 16.8% |
| 四月 | 210 | $28,400.00 | 15.5% |
| 五月 | 185 | $23,100.00 | 13.9% |
| 六月 | 260 | $35,200.00 | 18.0% |

### 💡 推荐操作：
1. 点击表格内任意单元格，触发侧边栏“求和与图表”面板。
2. 点击“一键数据图表化”按钮。
3. **折线图配置**：设置 X 轴为 `月份`，Y 轴勾选 `销量 (件)` 和 `净利润率`，设置标题为“上半年销量与利润率走势”。
4. **柱状图配置**：设置 X 轴为 `月份`，Y 轴勾选 `营业额 (元)`，设置标题为“月度营业额分析”。

## 场景二：项目工时与人力占比 (适合：饼图)

展示了团队在各项目模块上的工时投入。用于测试：
- X 轴（饼图扇区名称）：`项目模块`
- Y 轴（饼图占比数据）：`投入工时 (小时)`

| 项目模块 | 投入工时 (小时) | 团队负责人 |
| :--- | :--- | :--- |
| 底层数据库重构 | 120 | 张工 |
| 文本转表格 UI 联调 | 85 | 李工 |
| Kramdown 解释器优化 | 90 | 王工 |
| ECharts 图表化功能开发 | 45 | 赵工 |
| 暗黑主题样式适配 | 30 | 孙工 |
| 自动化回归测试编写 | 60 | 周工 |

### 💡 推荐操作：
1. 点击表格内任意单元格。
2. 在图表化对话框中选择 **图表类型** 为 `饼图 (Pie Chart)`。
3. 设置 X 轴为 `项目模块`，Y 轴勾选 `投入工时 (小时)`（此时由于是饼图，Y 轴会自动变为单选）。
4. 填写标题为“项目研发工时分布占比”，点击生成。

## 场景三：季度核心业务指标 (适合：双 Y 轴或对比折线图)

用于展示企业跨季度的用户增长与留存指标。用于测试：
- X 轴：`季度`
- Y 轴：`新增用户` (带千分位逗号的数字)、`周活跃率` 与 `次月留存率` (百分比数据)

| 季度 | 新增用户 (人) | 周活跃率 | 次月留存率 |
| :--- | :--- | :--- | :--- |
| 2025-Q1 | 12,450 | 68.5% | 45.2% |
| 2025-Q2 | 14,800 | 72.1% | 48.0% |
| 2025-Q3 | 19,250 | 75.6% | 51.5% |
| 2025-Q4 | 22,100 | 70.8% | 46.8% |

### 💡 推荐操作：
1. 打开配置对话框，选择 `折线图 (Line Chart)`。
2. 设置 X 轴为 `季度`，Y 轴勾选 `周活跃率` 和 `次月留存率`。
3. 观察折线图中的两条走势对比，清洗器将自动去掉 `%` 符号使其平滑展示。
