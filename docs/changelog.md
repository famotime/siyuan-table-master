# 表哥 (Table Master)

**专治思源 Markdown 表格的各种不爽！**

思源笔记表格增强插件 —— 把思源原生的 Markdown 表格进化为趁手的「轻量电子表格」，让你像用 Excel 一样流畅、智能、安全地编辑和计算数据。

## v1.2.0

### HTML 复杂表格高级编辑器

- **企业级商务主题预设**：内置 6 款精心调配的高保真配色风格（经典商务蓝、优雅薄荷绿、极简石墨灰、现代暗黑、经典网格线、清爽无边框），支持一键秒级换肤，并配备自定义底色/高亮保护机制；
- **拖拽拉伸与交互参考线**：
  - 单元格悬浮显现蓝色调整手柄，支持鼠标直接拖拽调整列宽与行高；
  - 拖拽过程实时呈现全局对齐参考线与动态尺寸气泡；
  - 支持单元格双击行内直接编辑；

- **内置公式计算引擎与向导弹窗**：
  - 支持可拖拽防遮挡的公式向导弹窗，激活时画布自动切入动态字母列与数字行坐标系（A1, B2...）；
  - 提供 9 种常用聚合与运算函数（`SUM`、`AVERAGE`、`COUNT`、`MAX`、`MIN`、`MEDIAN`、`PRODUCT` 及四则运算与括号表达式），支持实时结果预览与语法校验；
  - 支持相对引用与绝对锁定引用（如 `$A$1`）；
  - **智能填充**：公式相对坐标自动重定基，纯数字等差递增，文本批量复制；
- **排版变换与几何调整**：
  - **表格转置 (行列互换)**：一键将整表顺时针 90° 行列颠倒，完整保留样式与计算公式，内置合并单元格安全保护拦截；
  - **自适应与均分列宽**：一键清除固定尺寸自适应内容，或按列数等比例均分列宽（`table-layout: fixed; width: 100%`）；
  - **整行/整列复制与移动**：支持一键快速克隆整行/整列，支持行上下平移与列左右平移；
  - **智能数据排序**：支持按指定列升序 / 降序排序，智能识别数字、货币金额、百分比、日期与中文字符串，表头第一行自动锁定；
  - **9 宫格自由对齐**：水平对齐（居左/居中/居右）与垂直对齐（居顶/居中/居底）自由组合；
- **格式刷、冻结与样式精细微调**：
  - **格式刷**：支持十字刷取形态，一键批量刷入背景色、文字颜色、独立字号与对齐样式；
  - **独立冻结表头与首列**：支持独立开启 Sticky 固定表头与固定首列，长表与宽表滚动浏览更清晰，并配备区分性专属图标；
  - **专业调色板与全局微调**：提供 15 色商务调色板、行高/字号/边框/内边距精细微调（支持 0.1px 极细线及 Tooltip 悬浮说明），支持一键还原默认参数；
- **剪贴板智能清洗与安全导入导出**：
  - 导入原生 HTML 或 Markdown 代码时，自动剥离有害 XSS 脚本，清理微软 Office/Word 冗余垃圾标签，规范化 `<tbody>` 结构；
  - 支持一键提取完整内联样式 HTML 源码，或以制表符 (Tab) 分隔形式复制单元格纯文本到剪贴板。

### 原生 Markdown 表格与互转增强

- **双向转换与标题模型适配**：深度适配思源原生表格标题模型，HTML 表格与原生 Markdown 表格互转时标题与数据无缝保留；
- **排版与转换算法优化**：重构并提升 HTML ↔ NodeTable 转换算法的兼容性与结构保真度。

### 设置与系统体验优化

- **设置面板即时自动保存**：选项开关变更时即时自动保存并生效；
- **侧边栏与浮动工具栏联动**：优化 Dock 侧边栏工具箱与浮动工具栏的状态同步；
- **核心纯函数架构重构**：全面解耦转换、公式、样式与剪贴板模块；

## v1.1.6

- **多选单元格批量删除行 / 列**：支持选中多个单元格后，点击侧边栏或使用快捷键一键批量删除所有选中的整行或整列数据；

- **多单元格快捷计算兼容原生右键菜单**：优化多单元格框选与计算逻辑，实现快捷计算与思源笔记原生表格选区、右键菜单的无缝共存；

- **默认不启用行列拖拽按钮**：为避免与原生行列拖拽按钮冲突，将「启用拖拽行列重排 (`enableDragReorder`)」默认配置由开启调整为关闭。

## v1.1.5

### 新增 Markdown 表格相关功能

- **数据导出 CSV / XLSX**：将当前 Markdown 表格一键导出为标准 Excel (`.xlsx`) 文件或逗号分隔文本 (`.csv`) 文件；
- **表格转数据库**：将原生 Markdown 表格一键转换为数据库块；
- **全拆分**：将思源笔记中带有合并单元格的表格，一键拆分所有合并单元格。；
- **智能求和**：框选便捷计算支持带千分位分隔符的数字（如 `1,234.56`），百分比数字（如 `12.5%`）；


### 新增 HTML 表格编辑器

- **样式与排版精细调节**：
  - 支持可视化直接编辑行高、字号、边框宽度/颜色/样式、单元格内边距 (Padding)，并提供一键全局样式重置功能；
  - 支持右键菜单快捷操作、单元格选区跟踪、全选、表头/标题控制及单元格合并/拆分；
  - 提供单元格背景色拾取器与实时预览；
- **双向无缝转换 (HTML ↔ NodeTable)**：
  - 可视化编辑器内新增 **【转MD】** 按钮，可将编辑好的 HTML 表格直接转为思源原生 Markdown 表格（NodeTable）；

### 其他体验优化
- 提供一键生成示例Markdown表格与示例HTML表格功能；
- 右侧栏操作按钮重新布局；


## v1.0.0

在思源笔记中，表格是承载结构化信息的高频工具。然而，原生 Markdown 表格在实际使用中存在许多令人抓狂的痛点。表哥插件正是为此而生：

| 你的日常使用场景 | 原生思源体验 | 💻 使用表哥的体验与价值 |
| :--- | :--- | :--- |
| **数据迁移**：从 Excel / 网页 / 终端复制一段表格数据 | 粘贴后格式碎裂，变成一堆零散文本 | ✅ **智能粘贴**：自动识别多格式剪贴板，一键秒变标准表格，免去手动重构。 |
| **数据求和**：想临时算一下几行数据的总和与均值 | 必须手写公式或掏出计算器挨个累加 | ✅ **直接拖选计算**：鼠标直接框选，底部与侧栏秒显求和、均值与计数，甚至显示行列范围。 |
| **顺序调整**：调换行/列的顺序，或复制转移 | 只能靠繁琐的剪贴配合，极易弄乱已有数据 | ✅ **拖拽重排与插入粘贴**：拖拽手柄直观调整；**安全“插入式粘贴”**，不覆盖已有数据。 |
| **排版优化**：宽表格或长文本表格宽度难看 | 需要繁琐的手动拉伸或容忍难看的折行 | ✅ **一键列宽自适应**：点一下“调宽度”，表格根据内容自动紧凑排列，排版清爽。 |
| **长表浏览**：向下滚动阅读或编辑超长表格 | 表头滚出视口，完全分不清每列数据对应什么 | ✅ **钉住表头**：表头自动悬浮固定在视口顶部，长数据比对和补录清晰直观。 |
