## 1. 快速入门与入口介绍

在思源笔记中，您可以通过以下方式随时唤起 HTML 复杂表格可视化编辑器：

1. **光标悬浮工具栏**：光标移动到任意 HTML 表格块（`NodeHTMLBlock`）内部或边框时，点击浮动的 **【打开复杂表格编辑器】** 图标按钮；
2. **侧边栏工具箱 (Dock)**：在右侧/左侧插件工具面板中，点击【HTML 复杂表格】选项卡中的「编辑当前表格」；
3. **快捷命令**：在思源笔记中按下快捷键或斜杠命令输入 `/编辑HTML表格`。

## 3. 高频操作与排版变换

### 3.1 均分列宽与自适应排版

- **均分列宽 (`均分列`)**：
  - **点击入口**：顶部工具栏【均分列】按钮；
  - **功能效果**：自动将表格切换为严格等宽模式（`table-layout: fixed`），将所有列等比例均分（如 4 列各占 25%、6 列各占 16.67%），彻底解决长短文本参差不齐的问题。
- **自适应排版 (`自适应`)**：
  - **点击入口**：顶部工具栏【自适应】或侧面板【自适应】按钮；
  - **功能效果**：一键清除所有硬编码锁定的各列宽度与各行高度，表格自动根据单元格文本内容紧凑自然排版。

---

### 3.2 表格转置 (行列互换)

- **点击入口**：顶部工具栏【转置】按钮；
- **功能效果**：将整张表格顺时针 90° 行列颠倒（第 1 行变为第 1 列，第 2 行变为第 2 列...），单元格背景、文字、对齐与公式计算完整保留；
- **保护机制**：若表格中包含跨行跨列的合并单元格，系统会自动弹出提示拦截，避免意外损坏表格结构。

---

### 3.3 复制行列与智能排序

- **复制行 / 复制列**：
  - **操作方式**：点击选中某单元格，在侧面板或右键菜单中点击【复制行】或【复制列】；
  - **功能效果**：在当前行下方或当前列右侧克隆完整行/列（包含样式与公式相对位移）。
- **按列智能排序**：
  - **操作方式**：点击目标列的任意单元格，在侧面板或右键菜单点击【升序】（A→Z / 0→9）或【降序】；
  - **智能类型识别**：自动识别纯数字、金额货币（`¥`、`$`）、百分比（`98%`）、标准日期（`2026-08-16`）与普通中英文字符串；表头行自动锁定不参与排序。

---

### 3.4 合并与拆分单元格

- **合并单元格**：用鼠标按住拖拽框选多个连续单元格，在侧面板或右键菜单点击【合并】；
- **拆分单元格**：点击已合并的大单元格，在侧面板或右键菜单点击【拆分】，即可复原为独立网格。

## 4. 视觉美化与样式定制

### 4.1 商务预设主题一键套用

在顶部工具栏的【商务主题预设】下拉框中，内置了 6 套高规格配色风格，一键即刻换肤：

1. **经典商务蓝 (Business Blue)**：经典深蓝表头 + 白字加粗 + 浅蓝斑马交替纹理；
2. **优雅薄荷绿 (Mint Green)**：翡翠绿表头 + 清爽浅绿背景高亮；
3. **极简石墨灰 (Minimal Gray)**：深灰稳重表头 + 浅灰交替分割线；
4. **现代暗黑 (Modern Dark)**：深色背景 + 高对比度白字（切换回亮色主题时文字自动还原为黑色）；
5. **经典网格线 (Grid Frame)**：清晰 1px 实线框，适合数据密集型台账与清单；
6. **清爽无边框 (Clean Stripeless)**：仅保留极简水平底线，适合报告展示。

> **💡 自定义颜色保护机制**：
> 切换预设主题时，如果您曾经手动设置过特殊的单元格底色（如红色警告高亮）或彩色文字，系统会**智能保留您的个性化颜色**，仅更新默认底色与表头。

---

### 4.2 格式刷批量涂抹

1. 选中要采样的源单元格，点击侧面板或右键菜单中的【格式刷】按钮；
2. 光标会变为十字刷取形态；
3. 点击或按住拖选目标单元格区域，即可一键批量刷入源单元格的【背景色、文字颜色、字号、对齐方式】。

---

### 4.3 表头与首列冻结 (Sticky)

在侧面板【样式与主题】中：
- **冻结表头**：勾选后首行表头在上下滚动长表格时**常驻顶部可见**；
- **冻结首列**：勾选后首列在左右滚动宽表格时**常驻左侧可见**。

---

### 4.4 边框粗细与内边距精细控制

在顶部工具栏右侧区域：
- **行高 (倍数)**：输入数值（如 `1.4`）或点击 `+` / `-` 调节文本行距；
- **边框粗细 (px)**：支持从 `0.1px` 到 `10px` 精细边框微调；
- **内边距 (px)**：调节文字与单元格边框的留白边距（默认 `4px`）；
- **重置按钮**：一键还原为系统默认标准排版参数。

---

## 5. 鼠标直观拖拽与微操作

### 5.1 列宽与行高手柄拖拽

- **手柄感应**：鼠标悬停在任意单元格边缘时，右边缘与下边缘会自动显现蓝色交互高亮条；
- **拖拽调节**：
  - 按住右边缘左右拖拽：实时调整当前列宽；
  - 按住下边缘上下拖拽：实时动态撑开整行高度；
- **辅助指示**：
  - 画布上显示全局 **对齐参考虚线 (Guide Line)**；
  - 光标右上角跟随浮动 **尺寸提示气泡 (Resize Bubble)**，实时显示精确的像素与磅值（如 `列宽 140px · 105pt`）。

---

### 5.2 矩形区域平滑多格框选

- **多格框选**：按住鼠标左键从一个单元格拖拽滑动到另一个单元格，形成连续的蓝色矩形高亮选区；
- **批量操作**：框选后可一键执行批量合并、批量居中、批量填充背景色、批量清空样式；
- **底部状态栏即时计算**：框选多个含数字的单元格时，底部状态栏会**即时自动计算并显示总和与算术平均值**（如：`选中 6 格 · 求和: 8,450 · 均值: 1,408.33`）。

## 6. 公式计算与智能填充

### 6.1 插入公式向导与防遮挡拖拽

1. 选中要输出计算结果的单元格，点击顶部工具栏【公式】或右键选择【插入计算公式】；
2. 弹出公式输入向导弹窗；
3. **窗口自由拖拽**：鼠标按住弹窗顶部的**拖拽标题栏**，可将弹窗拖动到画布任意角落，随时移开窗口查看被遮挡的底层表格数据。

---

### 6.2 动态坐标系与语法帮助

- **表格坐标系标注**：打开公式弹窗时，表格上方会自动标注 **列字母（A, B, C, D...）**，左侧标注 **行号（1, 2, 3, 4...）**，并随选区动态高亮所在行与列；
- **语法帮助说明**：鼠标悬浮弹窗右上角的 **【?】问号图标**，会弹出详细的公式语法指南、区域冒号引用（如 `A1:A5`）与绝对锁定（`$A$1`）说明。

---

### 6.3 常用聚合函数速查

公式必须以 `=` 开头，支持直接点击弹窗内的快捷函数 Chips 填入：

| 快捷函数 | 示例 | 说明 |
| :--- | :--- | :--- |
| **SUM** | `=SUM(A1:A5)` 或 `=SUM(A1:D1)` | 对指定连续区域内所有数值求和 |
| **AVERAGE** | `=AVERAGE(B2:B10)` | 计算区域内有效数值的算术平均值 |
| **COUNT** | `=COUNT(C:C)` | 统计区域内包含数值的单元格数量 |
| **MAX** | `=MAX(A1:E5)` | 获取区域内的最大数值 |
| **MIN** | `=MIN(A1:E5)` | 获取区域内的最小数值 |
| **MEDIAN** | `=MEDIAN(B1:B9)` | 计算一组数值的中位数 |
| **PRODUCT** | `=PRODUCT(A1:A3)` | 将区域内所有数值连乘求积 |
| **四则运算** | `=A1+B1*1.2` 或 `=(A1+B1)/2` | 支持标准的加减乘除与括号运算优先级 |

---

### 6.4 智能填充 (公式位移与序号自增)

1. 选中包含公式或起始数据的单元格；
2. 框选需要填充的目标相邻单元格区域（向下或向右）；
3. 点击顶部工具栏【填充】或右键选择【智能填充】：
   - **公式单元格**：相对引用坐标自动沿填充方向重定基（如 `=SUM(A1:A5)` 向右填充变为 `=SUM(B1:B5)`）；绝对引用 `$A$1` 保持锁定不变；
   - **纯数字单元格**：自动识别为序列并按步长 +1 递增（如 `1` 自动填充为 `2, 3, 4...`）；
   - **文本单元格**：原样批量复制填充。

---

## 7. 外部导入与剪贴板清洗

- **外部导入**：点击顶部工具栏【导入】按钮，可直接粘贴外部 HTML 代码（`<table>...</table>`）或 Markdown 表格源码（`| a | b |`），一键转换并载入编辑器；
- **智能过滤清洗**：从 Word、Excel、网页等外部软件复制复杂表格粘贴时，系统会自动剥离有害的 XSS 脚本、清理微软 Office 特有的冗余垃圾标签（`mso-*`、`o:p`），并补齐残缺的 `<tbody>`、`<tr>` 结构，确保排版纯净稳定。

## 8. 快捷键与常用操作速查表

| 操作场景 | 快捷键 / 交互方式 | 说明 |
| :--- | :--- | :--- |
| **撤销操作** | `Ctrl + Z` | 撤销上一步排版、拖拽、公式或样式变更（最多保留 20 步） |
| **重做操作** | `Ctrl + Y` | 恢复刚才被撤销的操作 |
| **双击单元格** | 鼠标双击 | 进入单元格文字编辑模式；按 `Enter` 完成，`Shift+Enter` 换行 |
| **右键菜单** | 鼠标右键 | 唤出完整上下文快捷菜单（合并、对齐、公式、增删行列等） |
| **缩放画布** | 底部滑块 / 按钮 | 支持 `50%` ~ `150%` 缩放视图，方便查看超大超宽报表 |
| **保存更新** | `Ctrl + S` 或点击【保存】 | 将编辑好的完整 HTML 写入思源笔记文档中并无痕持久化 |
